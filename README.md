# Aurora S2x ⭐

> [!WARNING]
> S2x is **VERY EARLY** in development and is missing many features. There *will* be bugs and crashes.

This fork of S2x is maintained by Aurora to focus supporting both the Steam & Microsoft Store version of the game, adding modding utilities, and additional features to play the game comfortably. This fork **is not** meant to be used as a replacement to the original repository, and is primarily for research that will be upstreamed later.

To learn more about S2x itself, [check out S2x here.](https://github.com/Brentdevent/S2x) This includes [compiling the source code.](https://github.com/Brentdevent/S2x#compile-from-source-code)

## Aurora's Roadmap
